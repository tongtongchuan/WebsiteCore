# 01: 完善课程层级、内容附件及名称唯一性

Status: ready-for-human
Category: enhancement

Target repository: BZYA-Community/WebsiteCore
Publication: https://github.com/BZYA-Community/WebsiteCore/issues/84

## 问题描述与需求

1. 课程内容应按「课程分组 → 一个课程 → 一节课」组织，一个课程可以包含多节课。
2. 不应强制上传视频。
3. 应提供其他附件的上传渠道，例如文档、PPT 等。
4. 不应存在重名的课程分组，也不应存在重名的课程。

## 验收要点

- 可以按课程分组组织课程，并在一个课程下创建、展示多节课。
- 未上传视频时也能保存课程内容。
- 可以上传并访问文档、PPT 等非视频附件。
- 创建或修改课程分组、课程时，重复名称受到校验并给出明确提示。

## 待明确

- 课程名称唯一性是全局约束，还是仅限同一课程分组；名称的空格、大小写等如何判定。
- 视频及其他附件关联在课程还是单节课上，以及允许的文件类型、大小和数量。
- 已有课程内容的层级迁移方式及已有重名数据的处理方式。
