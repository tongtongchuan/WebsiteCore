# 01: 发帖默认公开，并改善可见性选项入口

Status: needs-triage

Target repository: BZYA-Community/WebsiteCore
Publication: https://github.com/BZYA-Community/WebsiteCore/issues/85

## 问题描述

用户反馈发帖默认私密，不符合用户直觉。可见性设置隐藏在「眼睛图标」中，并与附件等操作放在一起，用户不容易发现或理解。

## 预期行为

1. 新建帖子时，可见性默认应为公开，而非私密。
2. 改善可见性选项的入口及表达。用户建议在发帖框直接提供「公开 / 私密 / 仅关注」文字选项卡，或调整图标位置。

## 验收要点

- 新建帖子时默认选中公开，未主动修改可见性时按公开提交。
- 用户在发帖框能够容易发现、理解并切换可见性设置。
- 发布前能够明确识别当前所选可见性，提交结果与选择一致。

## 待明确

- 最终采用文字选项卡还是调整图标位置，以及桌面端、移动端的布局。
- 「仅关注」选项的准确含义及与现有权限规则的对应关系。
