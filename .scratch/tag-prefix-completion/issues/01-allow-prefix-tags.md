# 01: 标签自动补全阻止创建已有标签的前缀标签

Status: needs-triage

Target repository: BZYA-Community/WebsiteCore
Publication: https://github.com/BZYA-Community/WebsiteCore/issues/86

## 问题描述

用户无法创建与已有标签前缀相同、但更短的新标签。系统提示会强制补全已有标签，无法保留当前输入。

## 用户报告的复现步骤

1. 创建标签 `#123`。
2. 在标签输入处输入 `#12`，系统给出 `#123` 的提示。
3. 尝试按 `Enter` 或左方向键（`Left`）跳过提示、保留 `#12`。
4. 系统自动补全为 `#123`，无法创建 `#12`。

## 预期行为与验收要点

- 已存在 `#123` 时，仍可以创建独立的 `#12` 标签。
- 自动补全应允许用户保留当前输入并创建新标签，而非强制选择已有提示。
- 用户主动选择 `#123` 提示时，仍可正常使用该已有标签。

## 待明确

- 创建当前输入的新标签与选择已有建议的具体交互、键盘操作。
