# 〔BUG〕“话题”热门和最新列表展示待审核帖子的标签

Status: needs-triage

Target repository: BZYA-Community/WebsiteCore
Publication: https://github.com/BZYA-Community/WebsiteCore/issues/9

## 发生了什么

普通用户发布的帖子尚未通过审核，其标签已经出现在公开话题列表中。游客无法查看帖子正文，但能从话题接口获取标签、引用数和标签创建者信息。

## 复现步骤

1. 注册普通账号，发布一篇公开帖子，并附带此前不存在的唯一标签。
2. 确认发布响应中 `audit_status: 0`（待审核），不进行审核。
3. 以游客身份访问“话题”，分别查看“热门”和“最新”。对应请求为 `GET /v1/tags?type=hot&num=50` 和 `GET /v1/tags?type=new&num=50`。
4. 两个接口均返回该标签，且 `quote_num: 1`。
5. 游客请求 `GET /v1/post?id=<测试帖子ID>` 返回 HTTP 403，业务码 `20007`（无权限执行该请求）。

## 你预期应该发生什么

公开话题列表应只展示有已通过审核且公开可见帖子关联的标签。仅关联待审核帖子的标签，不应出现在游客可见的热门或最新话题列表中，也不应计入公开引用数。

## 实测记录

- 环境：本地运行服务 `http://127.0.0.1:8008`，通过 HTTP 接口验证。
- 测试身份：新注册的普通用户发帖，游客查询话题和帖子详情。
- 测试帖子 ID：`1080017992`。
- 唯一标签：`审核标签复现1790394617`，发布前确认不存在。
- 连续查询两次，热门和最新均出现该标签，帖子详情均返回 403。
- 测试结束后删除帖子成功，再查询最新话题时标签已消失。

## 影响

未经审核的标签文本会提前公开，绕过帖子审核对公开内容的限制。
